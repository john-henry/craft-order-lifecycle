Order Statistics

Solid analytics on order conversion rates, checkout durations, cart abandonment, and payment success rates, all through the dashboard widget.

Learn more

Timeline View

A clear, chronological timeline of every lifecycle event on the order edit page, with expandable JSON snapshots when you need to dig into the detail.

Learn more

Automatic Event Tracking

Captures cart, line item, coupon, address, customer, shipping, payment, and email events automatically - no extra code needed.

Learn more

Configurable Logging

Granular control panel settings let you enable or disable each event category on its own terms. IP addresses and user IDs are optional too.

Learn more

CSV Export

Export lifecycle events with your choice of columns and date/type filters, through the built-in utility.

Learn more

AI Insights

On-demand Claude-powered analysis of individual orders and store-wide metrics. Surfaces friction points, payment issues, and conversion patterns in plain language.

Learn more

Easy Integration

A Twig variable for manual checkout tracking, plus a clean PHP service API if you want to log custom events from your own code.

Learn more

API

Comes with a full CRUD API for managing lifecycle events and order statistics.
